# 🥁 Rhythm Tap Memo — リズムメモ

頭にふと浮かんだメロディーの「リズムだけ」を、スマホのタップで手軽に記録するためのツールです。
鼻歌を録音できない場所(職場など)でも、机の下でこっそりタップするだけでリズムを残せます。

音楽の知識は一切不要。楽譜も音名もわからなくて大丈夫です。

## 使い方

1. `index.html` をブラウザで開く(スマホ推奨)
2. 大きなパッドを **最初にタップした瞬間から記録開始**
3. 思いついたリズムのとおりにタップする
   - **長押しすると「長い音(伸ばす音)」** として記録されます
4. 「■ 記録おわり」を押すと、タイムラインが表示される
5. 「▶ 再生」で確認(速度も 0.5x〜1.5x で変えられます)
6. 「💾 保存」で名前をつけてブラウザに保存

## 職場向けの機能

- **🔇 消音モード** — 音を出さずに記録・確認できます(振動と光で再生)
- **📳 振動** — 再生時にリズムを振動で返します(Android のみ。iPhone は非対応)
- 記録中のタップ音もミュートされるので、静かな場所でも安心

## その他の機能

- **テンポ目安(♩≈BPM)** を自動で推定して表示
- 保存したリズムの一覧・再生・削除
- **JSON 書き出し / 読み込み** — 機種変更やバックアップ、PC との共有に
- PC ではスペースキーでもタップできます

## スマホで使うには

いずれかの方法で:

- **GitHub Pages を有効にする** — リポジトリの Settings → Pages でこのリポジトリを公開すると、
  `https://<ユーザー名>.github.io/<リポジトリ名>/rhythm-tap/` で開けます。
  ホーム画面に追加すればアプリのように使えます。
- **HTML ファイルを直接スマホに送る** — `index.html` 1ファイルで完結しているので、
  ファイルアプリ等から開くだけでも動きます。

## 技術メモ

- 依存ライブラリなし、単一 HTML ファイル(HTML + CSS + Vanilla JS)
- タイミング計測: `performance.now()`(ミリ秒精度)
- 再生音: Web Audio API でスケジューリング(タイミング正確)
- データ保存: `localStorage`(端末のブラウザ内。サーバーには何も送りません)
